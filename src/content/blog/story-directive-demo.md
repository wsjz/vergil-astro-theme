# Story 分镜脚本指令

将 Markdown 表格渲染为行式分镜列表。每行一个镜头，支持图片、标签、台词、备注等字段。

---

| 3 | 特写 | 2s | https://picsum.photos/300/200?random=3 | 一只手拍上她的肩膀 | |
:::

tab: 示例代码

`````markdown
:::story
| shot | scale | duration | image | desc | dialogue |
|------|-------|----------|-------|------|----------|
| 1 | 近景 | 3s | https://picsum.photos/300/200?random=1 | 教室里女配拿着手机准备发短信，喃喃自语 | 女配：我好钟意他啊，可是如果告白被拒绝了，那该多难为情啊 |
| 2 | 近景 | 5s | https://picsum.photos/300/200?random=2 | 女配放下手机失落地趴在桌子上 | 女配：我该怎么办 |
| 3 | 特写 | 2s | https://picsum.photos/300/200?random=3 | 一只手拍上她的肩膀 | |
:::
`````

- `shot` 列 **必需**，作为左侧镜号
- `image` 列支持 Markdown 图片语法 `![alt](url)` 或纯文本 URL
- `desc` 描述、`dialogue` 台词 为可选特殊列
- 其他任意列自动渲染为标签

## 列约定

| 列名 | 必需 | 说明 |
|------|------|------|
| `shot` | **是** | 镜号，渲染为左侧数字标识 |
| `image` | 否 | 图片，支持 `![alt](url)` 或纯文本 URL |
| `desc` | 否 | 描述文字，主内容区 |
| `dialogue` | 否 | 台词，左侧彩色竖线 + 斜体 |
| `note` | 否 | 备注，小字号灰色 |
| 其他 | 否 | 自动渲染为彩色标签 |
