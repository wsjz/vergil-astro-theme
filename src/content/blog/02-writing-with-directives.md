## 指令是什么

指令是写在 Markdown 里的特殊标记，构建时会变成真正的组件。语法只有两种。

容器指令用三个冒号包起来：

```markdown
:::callout{type="tip" title="小技巧"}
这里的内容会渲染成一个提示框。
:::
```

行内指令用一个冒号：

```markdown
这段话里有 :mark[高亮文字]{color="yellow"} 和 :kbd[Ctrl+C]。
```

## 从哪几个开始

50 个指令不用全记，日常写作用得最多的是这几个。

:::callout{type="tip" title="提示框"}
`callout` 有 info、tip、warn、danger 四种类型，用来强调容易被略过的信息。
:::

**选项卡** 适合并排展示同一件事的不同写法，比如「效果」和「代码」。**时间线** 适合项目进展、学习路径。**图片画廊** 一行写完一组图的网格排布。

## 不要过度使用

指令是为了让信息更好读，不是为了炫技。一篇文章里每隔两段就冒出一个彩色框，反而会让真正重要的内容失去重量。

整篇指令列表见 [内容指令](/docs/vergil-guide/03-基本创作/内容指令/)。
