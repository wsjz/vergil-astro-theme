# 安装 Docker

Docker 是 Kubernetes 最常用的容器运行时之一。本章介绍如何在 macOS、Windows 与 Linux 上安装 Docker。

## macOS

推荐使用 [Docker Desktop for Mac](https://docs.docker.com/desktop/install/mac-install/)。

## Linux

```bash
curl -fsSL https://get.docker.com -o get-docker.sh
sh get-docker.sh
```

## Windows

下载 [Docker Desktop for Windows](https://docs.docker.com/desktop/install/windows-install/) 并按照向导安装即可。
