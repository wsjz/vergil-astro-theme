# 简历配置

Vergil 内置简历视图，可将 Markdown 简历渲染为专业的在线履历页面。

## 文件位置

简历存放在 `src/content/resume/` 目录下，使用 Markdown 格式（`.md`）。

## 文件格式

```markdown
---
title: 简历
name: 张三
avatar: ../../assets/images/avatar.jpg
contact:
  email: zhangsan@example.com
  phone: 138****8888
  location: 北京
  website: https://example.com
---

## 个人简介

5 年前端开发经验，专注于 React 生态...

## 工作经历

### 某某公司 — 高级前端工程师

2022.03 - 至今

- 负责公司核心产品的前端架构设计
- 带领 5 人团队完成项目重构

## 教育背景

### 某某大学 — 计算机科学

2015.09 - 2019.06

## 技能

- React / Vue / TypeScript
- Node.js / Python
- Docker / CI/CD
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | 是 | 页面标题 |
| `name` | 是 | 姓名 |
| `avatar` | 否 | 头像路径 |
| `contact` | 否 | 联系方式 |

### contact 子字段

| 字段 | 说明 |
|------|------|
| `email` | 邮箱 |
| `phone` | 电话 |
| `location` | 所在城市 |
| `website` | 个人网站 |

## 访问路径

简历页面访问地址为 `/views/resume/`。

## 打印优化

简历视图已针对打印优化，按下 `Ctrl+P`（或 `Cmd+P`）即可打印为 PDF，排版整洁。

## 在导航中添加入口

在 `src/data/config/nav.ts` 中添加简历链接：

```typescript
headerNavLinks: [
    {
        label: '页面',
        children: [
            { label: '主页', href: '/' },
            { label: '简历', href: '/views/resume/' }
        ]
    }
]
```
