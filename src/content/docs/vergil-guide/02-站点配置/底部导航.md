# 底部导航

页脚导航链接配置在 `src/data/config/nav.ts` 的 `footerNavLinks` 字段中，会显示在网站底部版权信息的上方。

## 配置方式

```typescript
export const footerNavLinks = [
    { text: '关于', href: '/about' },
    { text: '联系', href: '/contact' },
    { text: 'GitHub', href: 'https://github.com/username' }
];
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `text` | 是 | 链接显示的文字 |
| `href` | 是 | 跳转地址。相对路径指向站内页面，完整 URL（以 `http://` 或 `https://` 开头）会自动在新窗口打开 |

## 建议配置

一个典型的个人博客配置：

```typescript
export const footerNavLinks = [
    { text: '关于', href: '/about' },
    { text: '联系', href: '/contact' },
    { text: 'GitHub', href: 'https://github.com/yourname' },
    { text: 'RSS', href: '/rss.xml' }
];
```

:::callout{type="tip"}
页脚导航建议控制在 3-5 个链接，保持简洁。过多链接会让页脚显得拥挤。
:::
