# 相册与多媒体

Vergil 内置了专为摄影作品设计的相册系统，支持双主题、多布局、EXIF 信息展示等功能。

## 本章内容

- [相册创建](./相册创建/) — 如何创建相册、配置图片和 EXIF 信息
- [主题与布局](./主题与布局/) — Golden/Seasons 双主题及布局选择

## 相册能做什么

相册是独立于博客的内容形式，适合展示摄影作品。一张图片可以附带：

- **标题与说明** — 描述照片背后的故事
- **EXIF 信息** — 相机型号、镜头、焦距、光圈、快门、ISO
- **季节标记** — 配合 Seasons 主题实现季节过滤
- **精选标记** — 让特定照片获得更大的展示空间

相册页面自带 Lightbox 功能，点击图片可全屏浏览，支持键盘/触摸导航。
