# 浮动音频播放器

浮动音频播放器是固定在页面右下角的小型音乐播放器，适合作为全局背景音乐使用。

## 效果

播放器以紧凑形式显示在页面右下角，包含播放/暂停按钮、进度条和音量控制。展开后显示封面图、歌曲信息和播放列表。

## 配置方法

在 `src/data/site-config.ts` 中修改 `floatingAudio` 字段：

```typescript
floatingAudio: {
    enabled: true,        // 是否启用
    autoplay: false,      // 是否自动播放
}
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `enabled` | 是 | `true` 启用播放器，`false` 关闭 |
| `autoplay` | 否 | `true` 页面加载后自动播放（受浏览器策略限制可能不生效） |

## 播放列表

播放列表需要额外配置。在 `src/data/site-config.ts` 中添加 `audioPlaylist` 字段：

```typescript
audioPlaylist: [
    {
        title: '歌曲名',
        artist: '艺术家',
        src: 'https://example.com/music.mp3',
        cover: 'https://example.com/cover.jpg'
    }
]
```

:::callout{type="tip"}
如果只需要在单篇文章中插入音频，使用 `:::audio` 内容指令更为灵活。浮动音频播放器适合作为全站背景音乐使用。
:::

## 关闭播放器

```typescript
floatingAudio: {
    enabled: false,
}
```
