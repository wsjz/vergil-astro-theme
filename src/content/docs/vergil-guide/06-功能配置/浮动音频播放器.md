# 浮动音频播放器

浮动音频播放器是固定在页面右下角的小型音乐播放器，适合作为全局背景音乐使用。

## 效果

播放器以紧凑形式显示在页面右下角，包含播放/暂停按钮、进度条和音量控制。展开后显示封面图、歌曲信息和播放列表。

## 配置方法

在 `src/data/config/features.ts` 中修改 `floatingAudio` 字段：

```typescript
floatingAudio: {
    enabled: true,
    autoplay: false,
}
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `enabled` | 是 | `true` 启用播放器，`false` 关闭 |
| `autoplay` | 否 | `true` 页面加载后自动播放（受浏览器策略限制可能不生效） |

## 关闭播放器

```typescript
floatingAudio: {
    enabled: false,
}
```
