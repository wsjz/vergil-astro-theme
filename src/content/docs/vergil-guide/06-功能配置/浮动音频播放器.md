# 浮动音频播放器

浮动音频播放器固定在页面右下角，用来集中播放**当前页面里用 `:::audio` 指令插入的音频**。它不是全站背景音乐——换一个页面，播放列表就换成那个页面的音频。

## 效果

播放器默认隐藏，点顶栏的音乐按钮才出现。紧凑形式包含播放/暂停按钮和进度条，展开后显示封面图、歌曲信息和播放列表。没有音量控制，音量跟随系统。

位置由 `src/styles/utilities/floating-stack.css` 的浮层槽位统一排布，会自动让开回到顶部按钮，不会互相遮挡。

## 配置方法

在 `src/data/config/features.ts` 中修改 `floatingAudio` 字段：

```typescript
floatingAudio: {
    enabled: true,
    autoplay: false,
}
```

## 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `enabled` | 是 | `true` 启用播放器，`false` 关闭 |
| `autoplay` | 否 | `true` 页面加载后自动播放（受浏览器策略限制可能不生效） |

## 关闭播放器

```typescript
floatingAudio: {
    enabled: false,
}
```
