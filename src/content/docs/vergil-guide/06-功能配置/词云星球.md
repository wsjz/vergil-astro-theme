# 词云星球

词云星球是标签页底部的一个 3D 交互式标签展示组件。所有标签以斐波那契球面分布排列，支持自动旋转、鼠标/触摸拖动交互。

## 配置方法

词云星球默认开启，在 `src/data/config/features.ts` 中修改 `tagCloud` 字段：

```typescript
export const tagCloud = {
    enabled: true,
};
```

## 关闭词云星球

如果不需要词云星球，将 `enabled` 设为 `false`：

```typescript
export const tagCloud = {
    enabled: false,
};
```

关闭后，标签页 `/tags/` 只显示顶部的标签列表，不再渲染底部的 3D 词云。
