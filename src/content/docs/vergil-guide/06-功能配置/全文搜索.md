# 全文搜索

Vergil 内置全文搜索功能，读者可以在网站右上角输入关键词，快速找到相关内容。

## 功能说明

搜索功能会自动索引以下内容：
- 博客文章标题和正文
- 页面标题
- 项目标题和描述

读者在搜索框中输入关键词后，系统会实时显示匹配结果，点击结果即可跳转到对应页面。

## 如何触发搜索

读者可以通过以下方式打开搜索：
- 点击网站右上角的搜索图标
- 使用键盘快捷键（默认配置下可用）

## 搜索效果

搜索支持模糊匹配，即使关键词不完全一致也能找到相关内容。例如搜索 "astro" 会匹配到包含 "Astro"、"astro" 的内容。

## 无需额外配置

全文搜索是 Vergil 内置功能，无需额外配置即可使用。只要你的文章正常存放在 `src/content/blog/` 目录下，系统会自动建立索引。
