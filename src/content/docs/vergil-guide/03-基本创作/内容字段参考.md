# 内容字段参考

本文档汇总 Vergil 所有内容类型的 frontmatter 字段，方便在写作时快速查阅。

---

## 博客文章 (blog)

文件位置：`src/content/blog/*.md`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | `string` | 是 | 文章标题 |
| `excerpt` | `string` | 否 | 摘要，不填则自动取正文前 200 字 |
| `publishDate` | `date` | 是 | 发布日期，格式 `YYYY-MM-DD` |
| `updatedDate` | `date` | 否 | 更新日期 |
| `isFeatured` | `boolean` | 否 | 是否精选，默认 `false` |
| `tags` | `string[]` | 否 | 标签列表 |
| `categories` | `string[]` | 否 | 分类路径，如 `["技术", "前端"]` |
| `series` | `string` | 否 | 所属专栏名称 |
| `draft` | `boolean` | 否 | 草稿，默认 `false` |
| `banner` | `string` | 否 | 封面图路径 |
| `seo` | `object` | 否 | SEO 覆盖，见下方 SEO 字段 |
| `fonts` | `object` | 否 | 单篇文章字体覆盖 |

### SEO 字段

```yaml
seo:
  title: 分享标题
  description: 分享描述
  image: /images/share.jpg
  pageType: article
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | `string` | 分享时显示的标题，5-120 字符 |
| `description` | `string` | 分享描述，15-160 字符 |
| `image` | `object` | 分享图片，`{ src, alt }` |
| `pageType` | `string` | `website` 或 `article`（默认）|

### 字体字段

```yaml
fonts:
  display: 'myFont'
  body: 'myFont'
```

| 字段 | 类型 | 说明 |
|------|------|------|
| `display` | `string` | 标题字体 |
| `body` | `string` | 正文字体 |

## 相册 (albums)

文件位置：`src/content/albums/*.md`

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `title` | `string` | 是 | 相册标题 |
| `description` | `string` | 否 | 相册描述 |
| `date` | `date` | 是 | 创建日期 |
| `cover` | `image` | 否 | 封面图 |
| `images` | `array` | 否 | 照片列表 |
| `tags` | `string[]` | 否 | 标签 |
| `theme` | `string` | 否 | 主题：`golden` 或 `seasons`，默认 `golden` |
| `layout` | `string` | 否 | 布局：`grid`、`masonry`、`timeline`、`carousel`，默认 `grid` |
| `photoFit` | `string` | 否 | 图片填充：`cover`、`contain`、`auto`，默认 `cover` |
| `background` | `string` | 否 | 自定义背景 |
| `accent` | `string` | 否 | 自定义强调色 |
| `seasonFilter` | `boolean` | 否 | 是否显示季节筛选，默认 `false` |
| `seasonDefault` | `string` | 否 | 默认季节：`spring`、`summer`、`autumn`、`winter` |
| `fonts` | `object` | 否 | 字体覆盖 |

### 照片字段

每张照片支持：

| 字段 | 类型 | 说明 |
|------|------|------|
| `src` | `image` | 照片文件（必填）|
| `alt` | `string` | 替代文字 |
| `caption` | `string` | 说明文字 |
| `season` | `string` | 季节：`spring`、`summer`、`autumn`、`winter` |
| `featured` | `boolean` | 是否精选 |
| `exif` | `object` | EXIF 数据 |

### EXIF 字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `camera` | `string` | 相机型号 |
| `lens` | `string` | 镜头 |
| `focal` | `string` | 焦距 |
| `aperture` | `string` | 光圈 |
| `shutter` | `string` | 快门速度 |
| `iso` | `string` | ISO |
| `datetime` | `string` | 拍摄时间 |
