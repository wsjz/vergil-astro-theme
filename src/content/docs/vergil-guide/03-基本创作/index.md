# 基本创作

本章介绍 Vergil 支持的各种内容形式，以及如何用内容指令美化你的文章。

## 本章内容

- [内容形式](./内容形式/) — 博客、图文动态、项目展示、知识库，该选哪种
- [内容指令](./内容指令/) — 30+ 指令速查：提示框、标签页、时间线、图片画廊等
- [内容组织](./内容组织/) — 专栏、分类、标签，三种方式的区别与用法
- [内容字段参考](./内容字段参考) — 所有内容类型的 frontmatter 字段速查表

如果你是第一次使用 Vergil，建议从 [博客写作](./内容形式/博客写作) 开始，写一篇文章熟悉流程后，再尝试内容指令。
