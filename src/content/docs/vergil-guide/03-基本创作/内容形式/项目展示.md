# 项目展示

项目用于展示你的作品、开源项目或其他成果，每个项目有独立的详情页面。

## 文件位置

项目存放在 `src/content/projects/` 目录下，使用 Markdown 格式（`.md`）。

## 文件格式

```markdown
---
title: Vergil 主题
description: 一个 Astro 个人博客主题
publishDate: 2026-04-23
isFeatured: true
---

## 项目概述

Vergil 是一个基于 Astro 的个人博客主题...

## 主要特性

- 支持多种内容形式
- 内置 30+ 内容指令
- 暗色/亮色模式切换

## 技术栈

- Astro
- Tailwind CSS
- TypeScript
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | 是 | 项目名称 |
| `description` | 否 | 项目简介，列表页展示 |
| `publishDate` | 是 | 发布日期 |
| `isFeatured` | 否 | 是否置顶，`true` 会在列表中优先展示 |

## 项目列表页

所有项目展示在 `/projects` 页面。设置了 `isFeatured: true` 的项目会排在最前面。

## 使用建议

- 每个项目写清楚项目背景、功能特性和技术栈
- 有实际成果（GitHub 仓库、在线演示）的优先展示
- 用 `isFeatured` 标记最重要的 2-3 个项目
