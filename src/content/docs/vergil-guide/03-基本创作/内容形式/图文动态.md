# 图文动态

图文动态是三种轻量化内容形式的统称：瞬间、想法和相册。它们都比博客文章更轻，适合快速记录和分享。

## 三种形式的区别

| | 瞬间 | 想法 | 相册 |
|--|------|------|------|
| 内容 | 图文动态 | 纯文本笔记 | 照片图集 |
| 格式 | JSON | Markdown | Markdown |
| 图片 | 支持多张 | 不支持 | 封面+多张照片 |
| 展示 | 时间线动态流 | 卡片流 | 网格/瀑布流 |
| 适用 | 生活碎片、短分享 | 灵感、观点 | 摄影作品、旅行记录 |

## 瞬间

瞬间类似于微博或朋友圈，适合发带图片的短动态。

### 文件位置

`src/content/moments/`，JSON 格式。

### 格式示例

```json
{
    "date": "2026-04-23",
    "content": "今天天气真好，去公园走了走。",
    "images": [
        "/images/moment-1.jpg",
        "/images/moment-2.jpg"
    ],
    "tags": ["生活", "户外"]
}
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `date` | 是 | 发布日期 |
| `content` | 是 | 动态内容，支持 Markdown |
| `images` | 否 | 图片路径数组，最多 9 张 |
| `tags` | 否 | 标签数组 |
| `linkCard` | 否 | 链接卡片（标题、描述、URL、图片） |
| `forward` | 否 | 转发内容（作者、内容、标签） |

### 图片布局

- 1 张：大图展示
- 2/4 张：2 列网格
- 3/5-9 张：3 列网格

## 想法

想法受 Flomo 启发，是纯文本的碎片化笔记，适合记录灵感和短思考。

### 文件位置

`src/content/thoughts/`，Markdown 格式。

### 格式示例

```markdown
---
date: 2026-04-23
tags:
  - 思考
  - 写作
---

写博客的意义不在于被多少人看到，而在于把模糊的想法变成清晰的语言。
```

### 特点

- 没有标题字段，纯文本卡片
- 建议每条不超过 140 字
- 超过 140 字自动折叠，可展开查看
- 支持标签筛选

## 相册

相册用于集中展示一组照片，支持封面图和照片说明。

### 文件位置

`src/content/albums/`，Markdown 格式。

### 格式示例

```markdown
---
title: 春日游记
description: 周末去植物园拍的照片
date: 2026-04-20
cover: ../../assets/images/album-cover.jpg
images:
  - src: ../../assets/images/photo-1.jpg
    alt: 樱花
  - src: ../../assets/images/photo-2.jpg
    alt: 郁金香
---

这次去植物园拍了不少照片，春天的花开得正好。
```

### 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `title` | 是 | 相册标题 |
| `description` | 否 | 相册描述 |
| `date` | 是 | 创建日期 |
| `cover` | 否 | 封面图 |
| `images` | 否 | 照片列表，每张可配 `alt` 说明 |
| `tags` | 否 | 标签 |

---

## 如何选择

- 发带图短动态 → **瞬间**
- 记一句话灵感 → **想法**
- 展示一组照片 → **相册**
