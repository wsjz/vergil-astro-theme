# 内容形式

Vergil 提供多种内容形式，每种形式对应不同的展示方式和适用场景。选择合适的形式，能让你的内容呈现得更加清晰。

## 形式一览

| 形式 | 路径 | 适合写什么 |
|------|------|-----------|
| [博客](./博客写作) | `/blog` | 长文章、教程、深度思考 |
| [图文动态](./图文动态) | `/moments`、`/thoughts`、`/albums` | 图文动态、短笔记、照片集 |
| [项目](./项目展示) | `/projects` | 作品展示、开源项目 |
| [知识库（Wiki）](./知识库搭建) | `/docs` | 系列文档、教程合集 |

## 如何选择

### 写长文章 → 博客

如果你要写一篇有结构、有深度的文章，比如教程、技术分享、读书笔记，选择**博客**。

博客支持标签、分类、专栏，文章会按时间倒序展示在 `/blog` 页面，最新的文章会出现在首页。

### 发图文动态 → 图文动态

如果你想快速记录生活碎片、发带图的短动态、或者整理一组照片，选择**图文动态**。

图文动态包含三种子形式：

- **瞬间** — 带图片的短动态，类似于微博（最多 9 张图，支持转发和链接卡片）
- **想法** — 纯文本的碎片化笔记，每条不超过 140 字
- **相册** — 照片图集，支持封面图和照片说明

它们都比博客更轻量，适合随手记录。

### 展示作品 → 项目

如果你有开源项目、设计作品或其他成果想展示，选择**项目**。

项目页面会展示项目的标题、描述和详细说明，支持置顶标记。

### 写系列教程 → 知识库（Wiki）

如果你要写一套成体系的文档或教程，比如"从零搭建博客"系列，选择**知识库**。

知识库支持层级目录、侧边栏导航、封面页，适合系统性内容的组织。

## 内容形式对比

```
内容长度：    想法 < 瞬间 < 相册 < 页面 < 项目 < 博客 < 知识库
结构化程度：  想法 < 瞬间 < 相册 < 页面 < 博客 < 项目 < 知识库
社交属性：    知识库 < 博客 < 项目 < 页面 < 相册 < 想法 < 瞬间
```

:::callout{variant="tip"}
一个网站可以同时使用多种形式。例如，在博客上写长文章，用瞬间记录日常，用想法收集灵感，用相册展示摄影作品。
:::
