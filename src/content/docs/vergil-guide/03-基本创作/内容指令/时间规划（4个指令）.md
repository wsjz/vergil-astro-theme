# 时间规划指令

用于时间管理、任务规划和目标跟踪的四个指令。

---

## 倒计时（deadline）

翻牌式倒计时器，适合项目截止、活动开始等场景。

::::tabs
tab: 演示效果

:::deadline{date="2026-12-31T23:59:59" title="新年倒计时" description="距离2027年还有"}
:::

tab: 示例代码

````markdown
:::deadline{date="2026-12-31T23:59:59" title="新年倒计时" description="距离2027年还有"}
:::
````

::::

- `date` — 目标日期时间，格式 `YYYY-MM-DDTHH:MM:SS`
- `title` — 倒计时标题
- `description` — 倒计时说明文字
- `showSeconds` — 是否显示秒，默认 `true`
- `expiredText` — 倒计时结束后的文字，默认「已截止」

---

::::

- `事件` — 事件名称

## 任务规划（plan）

多视图任务管理看板，支持 7 种展示模式。

::::tabs
tab: 演示效果

:::plan{title="项目开发计划" views="board,list,table,timeline,progress" default="board" dateCol="截止日期" progressCol="完成度" statusCol="状态" titleCol="任务" ownerCol="负责人" filters="状态,优先级"}
| 状态:status | 任务:text | 优先级:priority | 截止日期:date | 负责人:text | 完成度:progress |
|-------------|-----------|-----------------|---------------|-------------|-----------------|
| done        | 需求分析  | P0              | 2024-01-01    | Alice       | 100%            |
| done        | 技术选型  | P1              | 2024-01-10    | Bob         | 100%            |
| doing       | 前端开发  | P0              | 2024-02-01    | Carol       | 65%             |

````markdown
:::
````

::::

**支持的视图：**

| 视图 | 说明 |
|------|------|
| `board` | 看板视图，按状态分栏 |
| `list` | 列表视图，带筛选 |
| `table` | 表格视图 |
| `timeline` | 时间线视图 |
| `milestone` | 里程碑视图 |
| `progress` | 进度总览 |
| `ebbinghaus` | 艾宾浩斯遗忘曲线 |

**列类型（`列名:类型` 语法）：**

| 类型 | 说明 | 示例 |
|------|------|------|
| `text` | 纯文本（默认） | `任务:text` |
| `status` | 状态（`done`/`doing`/`todo`） | `状态:status` |
| `priority` | 优先级（`P0`/`P1`/`P2`/`P3`） | `优先级:priority` |
| `date` | 日期 | `截止日期:date` |
| `progress` | 进度百分比 | `完成度:progress` |
| `number` | 数字 | `评分:number` |
| `checkbox` | 勾选框 | `周一:checkbox` |
| `select` | 单选标签 | `类别:select` |
| `link` | 链接 | `文档:link` |

**常用属性：**

| 属性 | 说明 |
|------|------|
| `views` | 启用的视图 |
| `default` | 默认视图 |
| `groupBy` | 看板分组列 |
| `groupOrder` | 自定义分组顺序 |
| `filters` | 表格筛选列 |
| `dateCol` | 日期列映射 |
| `progressCol` | 进度列映射 |
| `statusCol` | 状态列映射 |
| `titleCol` | 标题列映射 |

## OKR 目标管理（okr）

Objectives and Key Results 目标管理，带进度条追踪。

::::tabs
tab: 演示效果

:::okr{title="Q2 产品目标" period="2026年第二季度"}
## O1: 提升用户体验

优化核心流程，降低用户流失率。

| Key Result | Target | Current | Description | Status |
|------------|--------|---------|-------------|--------|
| 页面加载时间 | 2s | 1.5s | 首屏加载优化 | 正常 |
| 用户留存率 | 80% | 75% | 7日留存 | 预警 |
| NPS 评分 | 50 | 45 | 用户推荐度 | 正常 |

进入两个新行业领域。

| Key Result | Target | Current | Description | Status |
|------------|--------|---------|-------------|--------|
| 新客户数 | 100 | 60 | 签约企业客户 | 正常 |
| 行业覆盖率 | 5 | 3 | 覆盖行业数量 | 滞后 |
:::

````markdown
## O1: 提升用户体验

| Key Result | Target | Current | Description | Status |
|------------|--------|---------|-------------|--------|
| 页面加载时间 | 2s | 1.5s | 首屏加载优化 | 正常 |
| 用户留存率 | 80% | 75% | 7日留存 | 预警 |
| NPS 评分 | 50 | 45 | 用户推荐度 | 正常 |

## O2: 拓展市场份额

进入两个新行业领域。

| Key Result | Target | Current | Description | Status |
|------------|--------|---------|-------------|--------|
| 新客户数 | 100 | 60 | 签约企业客户 | 正常 |
````

::::

- `title` — OKR 总标题
- `period` — 周期，如「2026年第二季度」
- `## O1:`、`## O2:` — 定义 Objective（目标）
- KR 表格列：`Key Result`、`Target`、`Current`、`Description`、`Status`、`Link`
- 自动计算进度：每个 KR 的进度 = Current / Target × 100%
