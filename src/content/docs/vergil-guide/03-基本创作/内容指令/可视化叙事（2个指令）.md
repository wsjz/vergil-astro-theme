# 可视化叙事指令

用于故事叙述、思维整理的可视化指令。

---

## 故事板（story）

分镜式故事板，适合剧本、视频分镜、产品场景描述。

::::tabs
tab: 演示效果

:::story
| shot | scale | duration | image | desc | dialogue |
|------|-------|----------|-------|------|----------|
| 1 | 近景 | 3s | https://picsum.photos/300/200?random=1 | 教室里女配拿着手机准备发短信，喃喃自语 | 女配：我好钟意他啊，可是如果告白被拒绝了，那该多难为情啊 |
| 2 | 近景 | 5s | https://picsum.photos/300/200?random=2 | 女配放下手机失落地趴在桌子上 | 女配：我该怎么办 |
| 3 | 特写 | 2s | https://picsum.photos/300/200?random=3 | 一只手拍上她的肩膀 | |
:::

tab: 示例代码

````markdown
:::story
| shot | scale | duration | image | desc | dialogue |
|------|-------|----------|-------|------|----------|
| 1 | 近景 | 3s | https://picsum.photos/300/200?random=1 | 教室里女配拿着手机准备发短信，喃喃自语 | 女配：我好钟意他啊，可是如果告白被拒绝了，那该多难为情啊 |
| 2 | 近景 | 5s | https://picsum.photos/300/200?random=2 | 女配放下手机失落地趴在桌子上 | 女配：我该怎么办 |
| 3 | 特写 | 2s | https://picsum.photos/300/200?random=3 | 一只手拍上她的肩膀 | |
:::
````

::::

**列说明：**

| 列名 | 必需 | 说明 |
|------|------|------|
| `shot` | ✅ | 镜头编号 |
| `image` | | 镜头图片 URL，支持 `![alt](url)` 或纯文本 URL |
| `desc` | | 场景描述 |
| `dialogue` | | 对白/台词 |
| `note` | | 拍摄备注 |
| 其他 | | 自动渲染为彩色标签 |

## 思维导图（mind）

基于 Markmap.js 的交互式思维导图，将 Markdown 列表渲染为可折叠的 SVG 脑图。

::::tabs
tab: 演示效果

:::mind
- Vergil 主题设计
  - 视觉系统
    - 配色方案
    - 字体层级
    - 间距规范
  - 交互系统
    - 纯 CSS 视图切换
    - 数据驱动渲染
    - 悬停动画效果
  - 指令生态
    - :::plan 多视图计划
    - :::timeline 时间轴
    - :::story 分镜脚本
:::

tab: 示例代码


::::

- 点击节点可折叠/展开
- 鼠标滚轮缩放，拖拽平移

- 需要网络加载 markmap.js（约 100KB）
